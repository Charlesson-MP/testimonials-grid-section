# 💬 Testimonials Grid Section

## 📖 About the Project

This project is a responsive testimonials grid section developed as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge. The goal was to recreate a testimonial layout featuring multiple user cards, using HTML and CSS while focusing on responsive design and modern layout techniques.

The layout adapts to different screen sizes, providing an organized and consistent experience across mobile, tablet, and desktop devices.

## ✨ Features

- Responsive layout for mobile, tablet, and desktop screens.
- CSS Grid with named grid areas for desktop positioning.
- Flexbox for flexible content organization.
- Individual testimonial cards with user information and profile images.
- Custom typography using Google Fonts.
- Adaptive layouts through CSS media queries.

---

## 🛠️ Technologies

The following technologies and tools were used in this project:

- **HTML5** – Semantic page structure and content organization.
- **CSS3** – Styling, layout, and responsive design.
- **CSS Grid** – Two-dimensional layout and card positioning.
- **CSS Flexbox** – Flexible alignment and content distribution.
- **Media Queries** – Responsive behavior across different screen sizes.
- **Google Fonts** – Custom typography.

## 📱 Responsive Design

The project uses CSS media queries to adapt the testimonial grid to different viewport sizes.

- **Mobile:** Single-column layout for better readability on smaller screens.
- **Tablet:** Two-column grid layout.
- **Desktop:** Multi-column grid using named grid areas to create the original testimonial arrangement.
